Overview

Sand UI is a purpose-built component system for SandurTech tools. It focuses on a monochromatic primary identity with a high-visibility accent system.

Sand UI in SandurTech Microservices

Microservice Layout Example

The typical layout for a SandurTech utility consists of a header, a configuration panel, and a result panel.

Buttons

Button Component

Description

Buttons trigger critical actions or events in our microservices.

When to Use

For generating results, submitting forms, or primary UI navigation.

How to Use

Apply sand-btn and a variant like sand-btn-primary.

import { Button } from '@sandurtech/sand-ui';

const App = () => (
  <Button variant="primary" onClick={generate}>
    Generate Results
  </Button>
);
<button class="sand-btn sand-btn-primary">Primary Action</button>

Inputs & Forms

Text Input
Please correct this field.

Description

Standardized form fields for user data entry.

When to Use

For configuration parameters, search boxes, and data submission.

How to Use

Wrap sand-input in sand-form-group with a sand-label.

import { InputGroup } from '@sandurtech/sand-ui';

const Form = () => (
  <InputGroup
    label="Microservice Name"
    error={true}
    helperText="Name is required"
  />
);
<div class="sand-form-group">
  <label class="sand-label">Label</label>
  <input type="text" class="sand-input">
</div>
